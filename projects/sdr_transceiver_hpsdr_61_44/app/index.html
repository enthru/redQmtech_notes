SDR transceiver compatible with HPSDR protocol 2

The SDR transceiver compatible with HPSDR is ready.

Now you can run the SDR programs that support the openHPSDR protocol 2, the one built on UDP ports 1024 to 1029 and 1035 upwards. Programs that speak only the original Metis protocol will not find this application.

The board reports itself as a Hermes with three DDCs. All of them run at the sample rate the host asks for on the lowest numbered one, because the gateware has a single decimation register; rates from 48 kHz to 1536 kHz are available.
